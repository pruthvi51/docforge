\begin{abstract}
Transforming unstructured medical records (clinical progress notes, discharge summaries, and laboratory reports) into standardized electronic health record ontologies (HL7 FHIR R4 and OMOP CDM) is hindered by high model inference costs, lack of posterior probability calibration, and excessive clinician audit burdens. We introduce \textbf{DocForge}, an open-source clinical document intelligence pipeline achieving \textbf{91.4\% entity extraction F1-score} across 15 clinical entity types. DocForge incorporates a deterministic-first cascade architecture integrating RapidFuzz fuzzy ontology matching with selective LLM reasoning, slashing token utilization by 42\% while sustaining processing throughput over 500K pages monthly. Furthermore, DocForge implements Platt scaling confidence calibration, routing only ambiguous extractions ($<$85\% confidence) to a human-in-the-loop clinician review queue, thereby compressing clinician verification volume by 73\% while maintaining 100\% clinical precision.
\end{abstract}

\section{Introduction}
Unstructured text accounts for over 80\% of patient electronic health records. Unlocking this telemetry for predictive clinical decision support and longitudinal cohort research requires structuring natural language prose into interoperable standards such as HL7 FHIR R4. However, naive end-to-end neural extraction pipelines incur prohibitive API latency, excessive token costs, and poor confidence calibration, inundating clinicians with manual verification queues.

To overcome these challenges, we design \textbf{DocForge}.

\section{System Architecture}
DocForge organizes document processing into four coordinated phases:
\begin{enumerate}
    \item \textbf{Topological DAG Pipeline Compiler:} Parses declarative JSON extraction specifications into acyclic execution graphs.
    \item \textbf{Deterministic-First Cascades:} Prioritizes regex and RapidFuzz ontology matches against ICD-10 and RxNorm lexicons before triggering LLM inference.
    \item \textbf{Platt-Scaled Calibration:} Evaluates posterior probability $P(\text{correct} \mid \text{score})$, routing low-confidence ($<85\%$) predictions to clinicians.
    \item \textbf{Standards Serialization:} Emits validated FHIR R4 JSON bundles and OMOP CDM observational records.
\end{enumerate}
